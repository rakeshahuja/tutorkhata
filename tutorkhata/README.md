# TutorKhata

**Fees ka hisaab, aasan.**

A one-person fee and invoice back office for home tutors. Data stays in the browser.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

Then open http://localhost:5173

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Data

All data is saved in browser localStorage under the key `tutorkhata.v1`. Clearing site data resets it.
